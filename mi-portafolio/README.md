## Ejecución

1. Descomprimir `mi-portafolio.zip`.
2. Abrir la carpeta `mi-portafolio`.
3. Abrir `index.html` en un navegador web.
4. Utilizar el menú de navegación para consultar las diferentes secciones.
5. La sección de contacto enlaza con `contacto.html`.
